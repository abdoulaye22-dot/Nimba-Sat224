# Nimba-Sat224
Student nanosatellite project — embedded systems, telemetry and ground station


INTRODUCTION: 
Nimba-Sat 224 est un projet de CubeSat expérimental né d'une passion pour l'électronique et l'exploration spatiale. Ce projet technique consiste en l'assemblage et la programmation d'un nanosatellite capable de collecter des données environnementales critiques en temps réel.
Équipé d'un capteur BME280 et d'un module GPS, le satellite mesure avec précision l'altitude, la pression atmosphérique et la température, tout en enregistrant ces informations sur une carte SD pour une analyse post-vol.

🎯 Objectifs Visés
Le projet Nimba-Sat 224 poursuit plusieurs buts essentiels :
1. Validation Technique : Maîtriser l'intégration hardware, de la soudure des composants à la gestion de l'alimentation par batterie.
2. Fiabilité des Données : Assurer une récupération parfaite des données de vol (télémétrie) via le stockage embarqué.

🛠️ Détails du Projet
 Cerveau du système : Microcontrôleur Arduino.
 Capteurs embarqués : BME280 (Pression/Humidité/Altitude) et GPS (Positionnement).
 Stockage : Module lecteur de carte SD pour la sauvegarde des logs de vol.
 Structure : Châssis optimisé pour la légèreté et la résistance.
